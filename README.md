**Problem:** Automate complex desktop form-filling in a transparent, explainable way.  
**Impact:** Built a visual computer-use agent that orchestrates a GPT-style VLM with a perception–reasoning–action loop, generating JSON action plans and executing precise pixel-level clicks and text entry.

**Problem:** Detect and track pedestrians across intersections for safety and planning.  
**Impact:** Deployed a YOLOv8 + DeepSORT system over hundreds of scenes, achieving >85% tracking accuracy and enabling trajectory-based analytics for urban environments.

**Impact:** Built an explainable pipeline using LoRA fine-tuned VLMs with Chain-of-Thought reasoning, achieving 78%+ accuracy on bias classification and generating human-readable rationales.

**Problem:** Turn structured family memories and lessons into personalized children’s storybooks.  
**Impact:** Designed a multi-agent GenAI platform where a root orchestrator coordinates Safety, Narrative, FactCheck, Pedagogy, Quiz, and Visual agents to produce safe, engaging stories with illustration prompts.

### 💬 WhatsApp Message Notification Router – Agentic RAG Workflow
**Problem:** Classify multimodal WhatsApp messages into notify / digest / mute actions for attention management.  
**Impact:** Built an agent-style router with metadata indexing, OCR, Whisper transcription, hybrid sparse+dense retrieval, rule-based safety filters, and confidence calibration, achieving high action accuracy on realistic message sets.
